使用说明

  1. 放底图（本地双击打开时必看）：把 18 张底图命名为 eagle-01.png ～ eagle-18.png，放进和本页面同目录的 images/ 文件夹。然后打开页面，点左侧最上面的【选择 images 文件夹】，在弹出的窗口里选中那个 images 文件夹 — 页面会把图片读成数据，下方会显示「已加载 X / 18 张图」。读进来之后，缩略图、预览和导出都用这份数据，不再被浏览器的本地跨域限制拦截。每次重新打开页面，都需要再选一次文件夹（浏览器不允许网页记住你硬盘上的文件夹）。在线打开本页面时底图会自动加载，这一步可以跳过。
  2. 切换模板：点左侧任意缩略图即可切换底图；每张图有自己独立的书写区预设，切换时正文 / 签名的微调偏移会自动归零，互不干扰。
  3. 对齐书写区：书写区不是固定死的。用左侧「书写区范围」四根滑杆（左边距 / 上边距 / 宽度 / 高度）把虚线框拉到当前底图真正的空白处，避开图标、吉祥物即可，整张卡片都能写；每张模板各自记住自己的范围。正文第一行默认「称呼顶格」不缩进（可在正文区取消勾选，恢复全部段落首行空两格），其余段落首行空两格。再用正文 / 签名各一组 ↑ ↓ ← → 方向键做 2px 精调，或直接在旁边的 X / Y 数字框里输入偏移量（方向键和数字框互相同步），点「重置」回到原位，两组完全独立。
  4. 字号：正文字号在左侧单独调；签名固定 24 号、日期固定 13 号，不跟着正文一起变。
  5. 替换底图：想换某一张图，直接用新图覆盖同名文件即可，换图后用滑杆重新对齐它的书写区就行，不用改代码。
  6. 导出：点【生成鼓励贴】直接按底图原图尺寸导出高清 PNG，文件名形如 鼓励贴_2026.11.24.png；辅助边框不会进入图片。如果提示生成失败，先确认上方显示「已加载 18 / 18 张图」— 本地打开时没选过文件夹，图片是直接从硬盘路径加载的，浏览器会出于安全限制拦住导出；选一次 images 文件夹读成数据后就能正常生成，建议用 Chrome / Edge 打开。

小提示：正文太长会被书写区裁掉，可拉高书写区高度、减小字号或缩短文字；签名选「右下角」时会与右下角的笔插画重叠，一般保持左下角。
